# Portfolio Professionnel

Un portfolio web moderne et responsif créé avec HTML et Tailwind CSS.

## Technologies utilisées
- HTML5
- Tailwind CSS
- JavaScript (pour les interactions)

## Sections incluses
- Header/Navigation
- Section Présentation (Hero)
- Section À propos
- Section Formation
- Section Expériences professionnelles
- Section Compétences
- Section Projets (2 projets minimum)
- Section Contact
- Footer

## Installation et déploiement

### 1. Cloner le repository
```bash
git clone https://github.com/votre-username/portfolio.git
cd portfolio
```

### 2. Ouvrir dans le navigateur
Ouvrez simplement le fichier `index.html` dans votre navigateur web.

### 3. Déploiement sur GitHub Pages
1. Créez un repository public sur GitHub
2. Poussez ce code vers votre repository :
   ```bash
   git remote add origin https://github.com/votre-username/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Allez dans Settings > Pages
4. Sélectionnez "Deploy from a branch"
5. Choisissez la branche `main` et le dossier `/ (root)`
6. Cliquez sur "Save"

### 4. Déploiement alternatif
Vous pouvez également déployer sur :
- **Vercel** : Connectez votre repository GitHub à Vercel
- **Netlify** : Glissez-déposez le dossier ou connectez votre repository
